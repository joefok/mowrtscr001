Classroom Screen Monitor

Teacher: Create room → share the student link.
Student: Open the link → click an empty seat → choose a screen and press Share.
Connection setup is automatic. Failed connections remain grey instead of disappearing automatically.

Lobby and connection status

Click an empty tile. The browser's screen picker should open immediately. No student name or pairing answer is required.

To retry a failed connection, stop sharing and click a seat again.

Diagnostics and limitations 

  
    
    
  • TURN allocation success does not prove that relay media ports are reachable.
    • 
    
  • ICE failed usually indicates a connectivity problem. Check coturn and firewalls.
    • 
    
  • Connected with bytes arriving but no decoded frames indicates a media/codec issue.
    • 
    
  • Firebase is used for lobby and signaling; WebRTC media is TURN-only.
    • 
    
  • One controlling teacher per room. Keep that browser open.
    • 
    
  • No automatic teacher failover or ICE restart is included.
    • 
    
  • Screen capture requires browser permission and a supported desktop browser.
    • 
    
  • Static content may continue producing frames and remain healthy.
    • 
    
  • Anonymous Firebase authentication does not verify real-world student identity.
    • 
    
  • Production needs stronger access control, temporary TURN credentials,
        abuse protection, and old-room cleanup.
