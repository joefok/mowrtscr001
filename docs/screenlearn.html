Diagnostics and limitations 

  
    
    
  • 3478 is the default ordinary TURN port. 5349 is the default TLS port.
    • 
    
  • Custom ports work only when coturn actually listens on them.
    • 
    
  • TURN/TLS requires a valid certificate and matching hostname.
    • 
    
  • Successful allocation does not prove media relay ports are reachable.
    • 
    
  • One controlling teacher per room; multiple rooms are supported.
    • 
    
  • Teacher must remain online. No automatic failover or ICE restart.
    • 
    
  • Browser approval for screen capture cannot be bypassed.
    • 
    
  • Production requires stronger authentication and temporary TURN credentials.
    •
