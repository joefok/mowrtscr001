Diagnostics and limitations 

  
    
    
  • A browser cannot silently capture a desktop; the screen picker is mandatory.
    • 
    
  • Use HTTPS and a supported desktop browser such as current Chrome or Edge.
    • 
    
  • Mobile screen-publishing support varies; mobile teacher viewing is supported.
    • 
    
  • One controlling teacher per room. Multiple separate rooms are supported.
    • 
    
  • The teacher browser must stay open. No coordinator failover is included.
    • 
    
  • Firebase handles discovery and signaling; coturn relays WebRTC video/data.
    • 
    
  • Grey means unavailable, connecting, or possibly stalled.
    • 
    
  • Static screens can remain healthy if encoded frames continue arriving.
    • 
    
  • Students are identified by authenticated browser ID and seat, not typed names.
    • 
    
  • Anonymous authentication is not verified school-account identity.
    • 
    
  • Production requires temporary TURN credentials, stronger access control,
      abuse protection, and old-room cleanup.
