Diagnostics and limitations 

  
    
    
  • One controlling teacher per room. Multiple independent rooms are supported.
    • 
    
  • Firebase handles lobby and signaling. coturn relays WebRTC video and data.
    • 
    
  • No automatic teacher failover. Keep the teacher browser open.
    • 
    
  • Anonymous authentication does not verify real-world student identity.
    • 
    
  • Screen capture requires HTTPS and a supported desktop browser.
    • 
    
  • Grey means unavailable, not sharing, or possibly stalled.
    • 
    
  • A static desktop can remain healthy if frames continue arriving.
    • 
    
  • Production needs verified accounts, temporary TURN credentials,
      abuse protection, and cleanup of old database records.
