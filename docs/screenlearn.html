Database REST connection

Firebase mode sends an ID token as the REST auth query parameter. Custom mode sends Authorization: Bearer and uses the UID entered here. Your server must verify the token and bind it to that UID. A typed UID alone is not authentication. Custom token is kept in sessionStorage.

The endpoint must support GET/PUT/PATCH/DELETE on .json paths, CORS for this GitHub Pages origin, and server-side authorization. Polling is used instead of proprietary Firebase WebSockets.

TURN configuration

TLS 443 needs a configured TURN TLS listener and trusted certificate. This field does not configure the server.

   Room settings in URLs are applied only by an authorized controller.
   start=1 does not bypass the required student click or browser capture prompt.
   Database endpoint/authentication are local connection settings and are not
   accepted from arbitrary URL parameters.
  

  

   Up to four active staff viewers receive separate student streams.
   Multiple viewers multiply student upload and TURN traffic. Use an SFU for
   larger deployments. Staff invitation links are sensitive bearer credentials.
   The server must enforce access control; hiding a button is not authorization.
