Database REST connection

No client authentication

  • No Firebase SDK or Firebase login.
  • No auth query parameter or Authorization header.
  • No cookies sent with database requests.

Requires GET, PUT, PATCH and DELETE on .json paths, multi-location PATCH with null deletion, JSON responses, and browser CORS. Polling is used instead of Firebase WebSockets.

Local browser IDs and private-link checks are not server authentication. An openly accessible database exposes records and invitation keys. Restrict access on the server/network as appropriate.

TURN configuration — relay only

TURN relay credentials remain required. No client authentication refers only to database requests. TLS 443 needs a real TURN TLS listener and trusted certificate. The hostname field does not configure the server.
