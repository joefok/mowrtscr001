Request compatibility

 

  
  
 


 

  Compatibility mode uses ordinary GET/PUT/PATCH/DELETE.
  It avoids ETag/If-Match request headers.
  Seat claims are best-effort and can briefly conflict.
 

 

  TLS, CORS, IP restrictions and server permissions cannot be bypassed here.
  Requests automatically retry, but actual server/browser rejection still
  needs a server-side correction.
